# กลยุทธ์ v2 (อธิบายภาษาคน)

ตัวเลขทุกตัวอยู่ใน `mt5kit/config/strategy-v2.json` ไฟล์นี้อธิบายความหมาย ไม่คัดลอกตัวเลข เพื่อไม่ให้ค่าไม่ตรงกัน
โค้ดที่ใช้จริง: `mt5kit/structure.py` (นิยาม) และ `mt5kit/setups.py` (รูปแบบ A/B), `mt5kit/engine.py` (Entry/SL/TP/อายุ)

## กรอบเวลา

- D1 = บริบท (โครงสร้าง + EMA50), High/Low เมื่อวาน (PDH/PDL)
- W1 = High/Low สัปดาห์ก่อน (PWH/PWL) ใช้เป็นเป้าหมายและระดับสภาพคล่องเท่านั้น
- H4 = ทิศทางหลัก (Swing High/Low 2 จุดล่าสุดสูงขึ้น = ขาขึ้น)
- H1 = รูปแบบเข้า จุดเข้า และ SL
- ใช้เฉพาะแท่งที่ปิดแล้ว

## ช่วงเวลา (เวลาท้องถิ่นของตลาด รองรับ DST)

- กรอบเอเชีย 00:00–07:00 ลอนดอน → สร้างระดับ High/Low ให้รูปแบบ B
- หน้าต่างลอนดอน 07:00–11:00 ลอนดอน และนิวยอร์ก 08:00–12:00 นิวยอร์ก → แท่ง BOS ต้องปิดในช่วงนี้
- วันทำการเริ่ม 17:00 นิวยอร์ก (ใช้นับโควตาวันละ 2)

## ทิศทางที่อนุญาต

| H4 | D1 | อนุญาต |
|---|---|---|
| ขาขึ้น/ขาลง | สนับสนุน หรือ เป็นกลาง | A หรือ B ตามทิศ H4 |
| ขาขึ้น/ขาลง | สวนทาง (โครงสร้างสวน **และ** ราคาอยู่อีกฝั่ง EMA50) | ไม่เทรด |
| เป็นกลาง | สนับสนุน | เฉพาะ B ตามทิศ D1 |
| เป็นกลาง | เป็นกลาง | ไม่เทรด |

## รูปแบบ A — ย่อตามเทรนด์ (ตัวอย่าง Long)

1. ขา H4 = จาก Swing Low ล่าสุด ถึงจุดสูงสุดหลังจากนั้น
2. H1 ย่อลงต่ำกว่าครึ่งขา (Discount) หรือแตะ FVG H4 ที่ยังไม่ถูกใช้ — ห้ามหลุดต้นขา
3. แท่งแรง (Displacement 1–3 แท่ง) + ปิดทะลุ Swing High H1 ที่เกิดระหว่างย่อ (BOS)
4. Entry = กึ่งกลาง FVG H1 แรกจากแท่งแรง (ไม่มี FVG → 50% ของช่วงแท่งแรง)
5. SL = ใต้จุดต่ำสุดของการย่อ + Buffer

## รูปแบบ B — กวาดสภาพคล่องช่วงตลาดเปิด (ตัวอย่าง Long)

1. ในหน้าต่างลอนดอน/นิวยอร์ก ราคาทะลุ Low กรอบเอเชีย / PDL / PWL แล้วปิดกลับภายใน 2 แท่ง H1 (ต้องเป็นการกวาดครั้งแรก)
2. ภายใน 6 แท่ง: แท่งแรง + ปิดทะลุ Swing High H1 ที่มีอยู่ก่อนการกวาด
3. Entry แบบเดียวกับ A, SL = ใต้จุดต่ำสุดของการกวาด + Buffer
4. ถ้าเข้าเงื่อนไขทั้ง A และ B = `A+B` ใช้ SL ที่แคบกว่า

## Entry / SL / TP / อายุ

- Buffer = ค่ามากสุดของ (0.10×ATR H1, 2×Spread, Stops level + 2 tick)
- ระยะ SL < 0.8×ATR → ขยายเป็น 0.8×ATR · > 3×ATR → ข้าม
- TP = ระดับที่ใกล้ที่สุดที่ยังไม่ถูกแตะ จาก Swing H4 ที่ยืนยัน / PDH-PDL / PWH-PWL / ขอบกรอบเอเชียฝั่งตรงข้าม (เฉพาะ B) — ห้ามข้ามระดับที่ใกล้กว่า
- R:R สุทธิหลังต้นทุน ≥ 1.5 · Spread ≤ 10% ของ SL · ต้นทุน ≤ 0.15R
- Pending หมดอายุเร็วสุดของ: 8 ชม.หลัง BOS, 17:00 นิวยอร์ก, เริ่มงดข่าว Tier 1, ศุกร์ 12:00 นิวยอร์ก

## ไม่นับสัญญาณเมื่อ

แท่ง Sweep หรือ BOS ครอบเวลาข่าว Tier 1 · มีข่าว Tier 1 เกิดหลัง BOS · โซนถูกแตะแล้ว · ราคาหลุด SL หรือถึง TP ก่อนเข้า
