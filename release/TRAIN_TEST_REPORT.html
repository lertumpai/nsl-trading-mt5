NSL price-action EA: training and test report

Single-file MT5 EA for EURUSD, GBPUSD and USDJPY. A separate 19-input logistic trade-quality filter per pair is embedded in the EA. Four causal setup rules construct stop-entry, stop-loss and structural target plans.

Research evaluation, not verified live performance. The report distinguishes actual MT5 generated-tick backtests from selected dataset scenario replay. Minute-bar spread proxies are included in published scenario gross labels; historical commission/slippage are unknown. A separate hypothetical 1.0 pip round-trip cost is subtracted in the scenario stress columns. No live orders were sent. The EA compiled with 0 errors and 0 warnings.

Actual MT5 Strategy Tester runs

These runs execute the frozen compiled EA against all available market bars in each calendar period, using MT5's M1 OHLC tick model, zero added execution delay, a 10,000 USD starting balance, 1:100 leverage, and 0.25% equity risk per order. Orders were enabled explicitly in the tester. Training period: 2016-11-08 through 2023-12-31. Held-out period: 2025-01-08 through 2026-11-06. No rules or weights were retuned using these reports.

The original global chronological splits and exclusions are preserved: training before 2024, validation in 2024, test from 2025 through the frozen 2026-11-06 23:57 broker-server cutoff. Seven-day embargo and full input/outcome interval purging come from the original manifest. No timestamps are converted to UTC.

Features use only the final closed M1/M5/M15 bars: signed body/ATR, range/ATR, close-to-EMA21/ATR, EMA9-to-EMA21/ATR, centered RSI14, tick-volume ratio20, and M1 spread/ATR. No IDs, paths, split flags, pattern/side labels, planned prices or outcomes enter the model. Train-only means/scales standardize features, clipped to ±8 train standard deviations. Missing/non-finite input rows are flagged and rejected for fitting and entry; they are never assigned a fabricated return target.

The binary target is a complete filled trade with published gross R minus the hypothetical cost greater than zero. Only complete training fills fit coefficients. Controls have no return target and are not assigned a fake zero. Unfilled, canceled, ambiguous and censored examples do not train the return filter. This creates label-availability selection bias, reported through separate status counts and unresolved stress.

For each pair, validation alone screens three L2 penalties (0.01, 0.1, 1.0) and nine thresholds (0.45 to 0.85). The objective is complete-fill cost-stress total R minus half closed-trade drawdown R, subject to at least 30 complete validation fills. All 27 configurations are recorded. If none meets the sample minimum, the first grid candidate is retained for diagnostic scoring only and tuning is marked unsuccessful. Models are frozen before test scoring; no refit includes validation or test.

Validation failed. EURUSD and GBPUSD have no candidate meeting the validation sample minimum. USDJPY meets the sample count but loses under the cost assumption. The resulting test scores also lose. Practical limits and installation

The underlying setups were machine selected, not human reviewed. Sample prevalence differs from all market minutes. The EA reproduces the causal signal/plan rules, but offline dataset quality gates include native-vs-M1 volume reconciliation over long windows. The EA checks closed-bar readiness, window spans and recent continuity; it does not re-audit every historical input window. This can materially change the number of trades, especially in training. Live quotes, broker constraints and feature seeding can differ. The supplied tester runs verify generated-tick operation on the source broker; they do not establish execution quality on another broker or real ticks.

Copy NSL_ShotTrader.ex5 to MT5's MQL5/Experts folder, refresh Navigator, and attach the same file once to each desired EURUSD, GBPUSD and USDJPY M1 chart (broker suffixes supported). Models select automatically by pair. No Python, model file, DLL or network access is required by the EA. For deliberate tester/demo experiments, enable Algo Trading and set EnableOrders=true. Real-account entry also requires AllowLiveAccount=true. Source is included for audit and recompilation.

Default risk is 0.25% of equity per chart, one pending order or position per symbol. There is no martingale. Stops and targets use pre-known structure, pending plans expire after 180 seconds and positions have a 600-second time stop. Indicators are seeded from 1,200 closed bars on each timeframe. Restarting starts a 15-minute signal warm-up; terminal disconnection prevents EA-managed cancellations and time stops, while broker-side SL/TP remain subject to execution.

Reproduce with python3 tools/train_ea.py. Detailed coefficients, split counts, thresholds, validation grid, status counts and baseline evaluations are in training_results.json. Per-event scores and accepted scenarios are in CSV files beside this report. Compilation, reproducibility and tester evidence are in verification.json.
