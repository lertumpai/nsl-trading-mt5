NSL ShotTrader — MT5 installation

The single runtime file is NSL_ShotTrader.ex5. It contains all three fitted
models. No DLL, Python process, CSV or external model is needed in MT5.

1. In MT5 choose File > Open Data Folder.
2. Copy NSL_ShotTrader.ex5 into MQL5/Experts.
3. Refresh Expert Advisors in Navigator (or restart MT5).
4. Attach the same EA once to each desired EURUSD, GBPUSD and USDJPY M1 chart.
   Broker prefixes/suffixes such as EURUSD# are supported; model selection is automatic.
5. The EA starts with EnableOrders=false. Read TRAIN_TEST_REPORT.html first:
   validation did not establish a usable trading edge.
6. For deliberate Strategy Tester or demo research, set EnableOrders=true and
   enable Algo Trading. For a tester run use M1, M1 OHLC or real ticks, and
   allow enough history for 1,200 closed bars of M1/M5/M15. Startup waits 15 minutes.
   Real-account entry additionally requires AllowLiveAccount=true.

The default fitted thresholds are 0.45 for all pairs. EURUSD and GBPUSD are
diagnostic fallback candidates because no grid candidate met the minimum
validation sample count. USDJPY's selected validation candidate lost money
under the research cost stress. Do not interpret a fitted score as a
calibrated probability of live profit.

RiskPercent defaults to 0.25% equity per chart. Below-minimum broker lot sizes
are skipped, never rounded up. An open position or pending order from any
source on that symbol blocks another entry. SL/TP are sent to the broker.
Pending plans expire after 180 seconds; position time stop is 600 seconds.
Spread/structural cancellation and time stops need the EA connected and receiving
ticks. EnableOrders=false blocks new entries but still manages its existing
orders/positions. On reload, anchor/cooldown memory resets after startup warm-up;
a previously used structural anchor may be considered again.

NSL_ShotTrader.mq5 is the readable source; open it in MetaEditor and press F7
to compile if needed. Keep one installed version per symbol/magic number.

Reports:
  TRAIN_TEST_REPORT.html       Human-readable training, tuning and test results
  training_results.json        Full metrics, grid, baselines and fitted parameters
  frozen_models.json           Model-selection snapshot written before test scoring
  verification.json            Compiler, reproducibility and tester checks
  mt5_runs/                   Native Strategy Tester reports and configuration evidence
  event_predictions.csv        Scores for the original temporal splits
  accepted_scenarios.csv       Selected scenario stream, including unresolved outcomes

Reproduce from the repository root:
  python3 tools/train_ea.py
  python3 tools/test_dataset_logic.py
  python3 tools/test_ea_training.py
  python3 tools/verify_ea_mt5.py

Do not change thresholds after reading test results and call the same test
unseen again. The shipped models were frozen before held-out scoring and
were not retuned using MT5 reports. Native tester runs use generated M1 OHLC
ticks, not verified real-tick execution.
