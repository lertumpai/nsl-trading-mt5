# ความเสี่ยงและการดูแลไม้เดิม

ค่าจริงอยู่ใน `account-profile.json` (ตัวอย่าง: `mt5kit/config/account-profile.example.json`) โค้ด: `mt5kit/risk.py`

## เพดาน (ค่าเริ่มต้น)

| รายการ | ค่า |
|---|---|
| ความเสี่ยงต่อไอเดีย | 0.25% ของ min(Balance, Equity) (สูงสุด 0.50% สกิลห้ามเพิ่มเอง) |
| รวม Positions + Pending | ≤ 1.00% |
| ต่อสกุลเงินต่อทิศ | ≤ 0.50% (เช่น Long EURUSD + Long GBPUSD = Short USD เต็มแล้ว) |
| ไอเดียพร้อมกัน / ต่อคู่ | ≤ 4 / ≤ 1 |
| ออเดอร์ใหม่ต่อวัน | ≤ 2 |
| ขาดทุนวันนี้ ≥ 0.75% / สัปดาห์ ≥ 2% | หยุดเปิดใหม่ |
| Drawdown ≥ 4% / ≥ 6% | ลดความเสี่ยงครึ่งหนึ่ง / หยุดเปิดใหม่ |

- Pending นับความเสี่ยงเต็ม Entry→SL · Position นับจากราคาปัจจุบันถึง SL
- ไม้ที่ไม่มี SL หรือคำนวณไม่ได้ → งดเปิดไม้ใหม่ทั้งบัญชี
- ไม้ Manual / EA อื่น นับความเสี่ยงด้วย แต่ห้ามแก้
- เงินต่อ lot ใช้ `tick_value` ของ MT5 (สูตรชั่วคราว) ต้องเทียบกับ Deal จริงบน Demo ก่อนใช้เงินจริง
- มาร์จินเป็นค่าประมาณจาก Leverage จนกว่าจะมี OrderCalcMargin

## คำตัดสินไม้เดิม (`management` ในผลสแกน)

| Action | ความหมาย | ใครทำ |
|---|---|---|
| KEEP | ยังตรงแผน | — |
| CANCEL | Pending ของสกิลหมดเหตุผล (H4 เปลี่ยน, ข่าว Tier 1 กำลังมา, ไม่มี Expiry) | โหมดวางเลย: ส่งด้วย `--include-cancels` · โหมดแผน: เสนอ |
| MODIFY_SL | ได้ ≥ +1R และมี Swing H1 ใหม่ → เลื่อน SL ไปหลัง Swing (`new_sl`) | ผู้ใช้ต้องสั่ง |
| PROPOSE_CLOSE | ถือ 24 แท่ง H1 ยังไม่ถึง +0.5R / ครบ 5 วัน / กฎวันศุกร์ | ผู้ใช้ต้องสั่ง |
| REPORT_ONLY | ไม่ใช่ไม้ของสกิล | ห้ามแก้ |

ห้ามขยาย SL ออก ห้ามถัวล็อต ห้ามปิดบางส่วน (MCP ยังไม่รองรับ)
