# รายงาน HTML

`python3 -m mt5kit render --run <run_id>` สร้าง `runs/<run_id>/report.html` (ไฟล์เดียว เปิดออฟไลน์ได้) จาก `report.json` + `narrative.json`
โมเดลเขียนแค่ `narrative.json` เท่านั้น ห้ามแก้ HTML หรือ report.json เอง

## narrative.json

```json
{
  "overview": "ไม่เกิน 4 ประโยค ภาษาไทยง่าย ประโยคสั้น: ตอนนี้ควรทำอะไร เพราะอะไร",
  "per_plan": {
    "P-20261109-EURJPY-L-B-0800": [
      "การกวาด Low ช่วงเอเชียแล้วปิดกลับ อาจเป็นจุดที่ผู้เล่นรายใหญ่ใช้สภาพคล่องฝั่งขายเพื่อเข้าซื้อ",
      "Macro ของ JPY อ่อนลงหลัง BoJ คงนโยบาย จึงหนุนฝั่ง Long"
    ]
  },
  "macro_note": "(ไม่บังคับ) สรุป Macro ภาพรวม 1–2 ประโยค"
}
```

- ต่อแผนไม่เกิน 3 ข้อ ข้อละไม่เกิน 200 ตัวอักษร ทุกข้อแสดงป้าย "ข้อสันนิษฐาน" (ข้อมูลจริงโค้ดใส่เอง)
- ห้ามมีราคา/ล็อต/เงิน ที่ไม่ตรงกับแผน (render จะตัดทิ้งและแจ้งใน `issues`)
- ใช้ plan_id จากผลสแกนเท่านั้น
- ไม่มีแผน: `per_plan` ว่างได้ ส่วน `overview` บอกว่ารออะไร

## สิ่งที่รายงานแสดง (โค้ดสร้างให้)

แถบคำตัดสิน + โหมด · การ์ดทุน · ความเสี่ยงก่อน/หลัง + Heatmap สกุลเงิน · ข่าวถัดไป · ไม้ค้าง ·
การ์ดแผน: กราฟแท่งเทียนจริง (แท็บ H1/H4/D1) มีเส้น Entry/SL/TP พร้อมเงิน, กล่องเสี่ยง/กำไร, โซน FVG/Discount/กรอบเอเชีย, PDH/PDL/PWH/PWL,
ป้าย ①Sweep ②BOS ③FVG, เส้นประฉากทัศน์ "ถ้าเป็นตามแผน/ถ้าผิดทาง", เส้นหมดอายุ, เส้นข่าว · ตารางสแกน 10 คู่ · Macro/COT · ผลดำเนินการ · ข้อจำกัด

## คำตอบในแชต

สั้น 3–6 บรรทัด + ที่อยู่ไฟล์ ไม่ต้องคัดลอกตารางยาวจากรายงาน
