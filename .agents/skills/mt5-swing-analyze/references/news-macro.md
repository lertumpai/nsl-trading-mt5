# ข่าวและ Macro

## ข่าว (โค้ดจัดการให้ — `mt5kit/news.py`, รายการ Tier 1 ใน `mt5kit/config/news-tier1.json`)

- **Tier 1**: มติดอกเบี้ย/แถลงข่าวธนาคารกลาง, CPI, รายงานแรงงานหลัก, US Core PCE → ห้ามมี Pending ตั้งแต่ 2 ชม.ก่อนถึง 1 ชม.หลัง
- **Tier 2**: ข่าวความสำคัญสูงอื่นในปฏิทิน MT5 → ห้าม Pending คร่อม ±30 นาที
- งดเฉพาะสกุลเงินที่อยู่ในคู่นั้น (ข่าว USD ไม่บล็อก EURJPY/AUDJPY/EURGBP)
- ทอง XAUUSD/GOLD# ใช้ข่าว USD และนับสกุลเป็น XAU/USD แม้โบรกเกอร์คืนสกุลฐานเป็น USD
- อ่านปฏิทินไม่ได้ → งดเปิดไม้ใหม่ (ดูแลไม้เดิมได้)

## ไฟล์ Macro รายวัน `runs/macro/<วันที่>.json`

สร้างด้วย `python3 -m mt5kit macro-template` แล้วกรอก:

```json
{
  "date": "2026-11-09",
  "currencies": {
    "USD": "Fed คงดอกเบี้ย ส่งสัญญาณรอดูเงินเฟ้อ; ตลาดคาดลดครั้งถัดไป ธ.ค. (สั้น 1–2 ประโยค)",
    "JPY": "..."
  },
  "pairs": {
    "USDJPY": {"long": "neutral", "short": "neutral"},
    "EURUSD": {"long": "support", "short": "neutral"}
  },
  "sources": [{"title": "FOMC statement", "url": "https://...", "published": "2026-11-05 14:00 ET"}]
}
```

ค่าใน `pairs`: `support` (ข่าวหนุนทิศนี้) · `neutral` · `conflict` (ขัดแย้งชัดเจน = **ห้ามเทรดทิศนี้วันนี้**)

แนวทางกรอก (รายละเอียดเต็มในสกิล `mt5-macro-news`):

1. ใช้แหล่งต้นทางก่อน: เว็บไซต์ธนาคารกลาง (Fed, ECB, BoJ, BoE, RBA, RBNZ, BoC) และหน่วยงานสถิติ แล้วค่อยสำนักข่าวที่ตรวจสอบได้
2. ต่อสกุลเงิน: ทิศนโยบาย + สิ่งที่ตลาดคาดไว้แล้ว, ข้อมูลล่าสุด Actual เทียบ Forecast, ปัจจัยพิเศษ (แทรกแซงค่าเงิน, น้ำมัน, จีน, หนีความเสี่ยง)
3. ใส่ `conflict` เฉพาะเมื่อชัดจริง เช่น ธนาคารกลางเพิ่งเปลี่ยนท่าทีแรงสวนทิศ หรือมีความเสี่ยงแทรกแซงค่าเงินชัดเจน
4. ใส่ URL และเวลาเผยแพร่ทุกแหล่ง ห้ามสร้างตัวเลขที่หาแหล่งไม่ได้

## COT

`python3 -m mt5kit cot` ดึง Traders in Financial Futures จาก CFTC (cache 3 วัน) ใช้เป็นบริบทเท่านั้น ไม่เพิ่มคะแนน
ถ้าดึงไม่ได้ รายงานจะเขียนว่า "ไม่มีข้อมูล COT" — ห้ามสร้างข้อมูลแทน
