# MT5 Symbol Analyze

เลือกวิเคราะห์สินทรัพย์เดียวจากรายการในกลยุทธ์ โดยใช้ข้อมูลจริงจาก MT5 และตรวจความเสี่ยงรวมทั้งบัญชี ค่าเริ่มต้นของคำสั่งรายตัวเป็น `plan_only` จึงไม่ต้องถามโหมดซ้ำเมื่อผู้ใช้ขอวิเคราะห์หรือรายงานอย่างเดียว

## วิธีเรียก

- `วิเคราะห์รายตัว XAUUSD`
- `วิเคราะห์ EURUSD พร้อม report`
- `$mt5-symbol-analyze XAUUSD`

ผู้ใช้ตั้งค่าเริ่มต้นของโปรเจกต์เป็น **ทอง XAUUSD ตัวเดียว** ถ้าคำขอไม่ระบุสินทรัพย์ให้ใช้ XAUUSD ได้เลย หากระบุชื่อเองให้ใช้ตามคำขอ รองรับชื่อมาตรฐานในกลยุทธ์และ alias ทอง `GOLD`/`GOLD#` → `XAUUSD` คำสั่งจะปฏิเสธชื่อที่อยู่นอกกลยุทธ์

## ขั้นตอน

ทำงานจากรากโปรเจกต์:

1. รัน `python3 -m mt5kit status` ถ้ามี `next_steps` ให้แก้ตาม [คู่มือตั้งค่า](../mt5-swing-analyze/references/setup.md) ถ้ามีรอบอื่นล็อกบัญชีให้รอ
2. ใช้ Macro ของวันทำการเดียวกัน ถ้ายังไม่มีให้ทำตามสกิล `mt5-macro-news` ก่อน
3. รันคำสั่งต่อไปนี้โดยแทนชื่อสินทรัพย์ตามที่ผู้ใช้เลือก:

   ```bash
   python3 -m mt5kit analyze XAUUSD
   ```

   คำสั่งจะสร้าง `report.json` และ `report.html` พร้อมคืน `run_id`, `narrative_file`, `report_html` ชื่อโฟลเดอร์มีชื่อสินทรัพย์เพื่อไม่ทับรายงานรวม หากได้ `error` ให้แจ้งตามจริง
4. เขียน `narrative_file` ตาม [รูปแบบรายงาน](../mt5-swing-analyze/references/report.md) โดยใส่ภาพรวม เหตุผลแผนที่ผ่าน และ `per_watch` ของสินทรัพย์ที่เลือก ใช้ตัวเลขจากผลสแกนเท่านั้น ถ้ายังไม่มีจุดเข้าให้บอกเงื่อนไขที่รอและเหตุผลที่ยังไม่ผ่าน
5. รัน `python3 -m mt5kit render --run RUN_ID` แล้วส่งลิงก์ไฟล์รายงานพร้อมสรุปสั้น ๆ

รายงานแสดงกราฟรายตัวแม้ทิศทางยังไม่ผ่านกฎ รวมข่าวและ Macro ที่เกี่ยวข้องกับสินทรัพย์นั้น ส่วนความเสี่ยงบัญชีรวมไม้ทั้งหมด ไม้ของสินทรัพย์อื่นมีสถานะ `REPORT_ONLY` ในรอบนี้

## เมื่อผู้ใช้ขอวางออเดอร์ด้วย

ใช้สกิล `mt5-swing-analyze` ในโหมดที่ผู้ใช้ระบุ พร้อมตัวเลือก `--symbol` เช่น `python3 -m mt5kit scan --symbol XAUUSD --mode analyze_and_place` แล้วส่งต่อแผนที่ผ่านให้ `mt5-swing-execute` ตามขั้นตอนเดิม

ห้ามเปลี่ยนพารามิเตอร์กลยุทธ์เพื่อให้เกิดสัญญาณ คำนวณราคาและล็อตผ่าน `mt5kit` เท่านั้น และไม่แสดง Token หรือเลขบัญชีเต็ม
